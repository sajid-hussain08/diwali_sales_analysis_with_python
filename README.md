# 🪔 Diwali Sales Data Analysis using Python
## 📊 Overview

This project performs an Exploratory Data Analysis (EDA) on Diwali Sales Data to uncover useful business insights and customer purchasing patterns.
Using Python libraries like NumPy, Pandas, Matplotlib, and Seaborn, the dataset is cleaned, analyzed, and visualized to identify the target audience for marketing strategies during the Diwali season.

## 🧠 Objectives

- Clean and preprocess the sales dataset
- Perform EDA to identify patterns and correlations
- Visualize customer behavior and sales performance
- Generate business insights to improve marketing focus****

## 🧰 Technologies & Libraries Used

- Python 🐍
- NumPy – for numerical computation
- Pandas – for data cleaning and analysis
- Matplotlib – for data visualization
- Seaborn – for advanced visualizations

## 🔍 Key Steps in Analysis

**1. Data Cleaning**
- Removed null and duplicate values
- Converted data types where necessary<br>
**2. Exploratory Data Analysis (EDA)**
- Gender-wise and age-group-wise purchase patterns
- State-wise total sales
- Occupation and product category insights
- Visualization using Seaborn and Matplotlib<br>
**3. Visualization**
- Bar plots and count plots for gender, age, and occupation
- State-wise and category-wise sales comparison
- Correlation heatmaps for numeric variables

## 💡 Insights & Conclusion

- **Married women aged 26–35 years** from **Uttar Pradesh, Maharashtra,** and **Karnataka**
working in **IT, Healthcare,** and **Aviation** sectors
**are more likely to buy products from the Food, Clothing, and Electronics categories.**
- These insights can help businesses target marketing campaigns more effectively during festive seasons like Diwali.
